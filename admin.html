GitHub Auto-Deploy

Connect your GitHub repository so every Save automatically commits to your live site. Changes deploy within ~30 seconds.

Create a token at github.com/settings/tokens with Contents: Write permission. Stored in your browser only.
How it works: After saving your GitHub token, every time you click Save on a tool or the site config, changes are automatically committed to js/tools-data.js and index.html in your repo. Your site updates within 30 seconds — no copy-paste needed.
