GitHub Auto-Deploy

Connect your GitHub repository so every Save automatically commits to your live site. Changes deploy within ~30 seconds.

Create a token at github.com/settings/tokens with Contents: Write permission. Stored in your browser only.
How it works: Every Save automatically commits to GitHub — tool overrides, affiliate URLs, and site config are all synced. Using a new device or browser? Enter your token above and click Save & Sync from GitHub to restore all your saved data instantly. Your GitHub token is the only thing you need to re-enter on each new device.
